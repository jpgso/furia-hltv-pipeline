Como este álbum é feito

Nada aqui é digitado à mão. Uma esteira de dados em arquitetura medalhão, só com ferramentas gratuitas, refaz a página a cada carga de partidas novas.

  1. BronzeCada página de partida da HLTV fica guardada como veio, compactada, e serve de fonte para todo o resto.
  2. LimpezaConsultas SQL no DuckDB transformam o HTML em fatos e dimensões, sempre do ponto de vista da FURIA.
  3. AnáliseOutra camada de SQL monta as tabelas prontas para consulta. Sete delas viram os arquivos que esta página lê.
  4. RotinaUm fluxo no n8n roda a carga quando o computador liga e uma vez por dia, às 21h, e avisa por e-mail e WhatsApp quando entra partida nova.

Projeto de fã, sem fins comerciais e sem vínculo com a FURIA ou com a HLTV. Os dados são da HLTV.org; se você é titular e quer a remoção, peça aqui. Código e documentação no GitHub.
